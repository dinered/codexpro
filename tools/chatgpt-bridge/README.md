# Мост Paseo → ChatGPT

Учебный (ai/codexpro#2 п. 6): редкие короткие прогоны в рабочей сессии, оператор
рядом. Запускает только человек, вручную — не фоном и не по расписанию.

## Условия OpenAI и риск для аккаунта

Мост вводит текст в веб-интерфейс ChatGPT и программно забирает ответ. Условия
использования OpenAI ([Terms of Use](https://openai.com/policies/terms-of-use/),
раздел «What you cannot do») это запрещают:

> Automatically or programmatically extract data or Output (defined below).

> Interfere with or disrupt our Services, including circumvent any rate limits or
> restrictions or bypass any protective measures or safety mitigations we put on
> our Services.

За нарушение OpenAI может приостановить доступ или удалить аккаунт: «We reserve
the right to suspend or terminate your access to our Services or delete your
account». Цитаты — по редакции от 11 декабря 2024 г., сверены 2026-10-09 по её
копии; openai.com автоматике отвечает 403, актуальную редакцию сверять в браузере.

Поэтому:

- мост учебный: прогоны редкие и короткие, запущенным «на всякий случай» его
  не держим;
- никакой маскировки под человека: ни stealth-плагинов, ни подмены отпечатка
  браузера, ни случайных задержек, ни решения капч. Капча или лимит ChatGPT —
  мост останавливается (раздел «Предохранители»);
- ученикам: код читать и тесты гонять на имитации (`tests/e2e/fake-chatgpt.html`),
  мост на своём аккаунте ChatGPT не запускать.

## Как работает

Плагин Paseo (`tools/paseo-plugin`) и мост обмениваются файлами в папке
`.ai-bridge/paseo/<сессия>/` рабочей папки агента. Правила обмена — протокол v2,
он описан и проверен в одном модуле `tools/paseo-plugin/server/protocol.ts`,
который используют обе стороны.

| Файл | Кто пишет | Зачем |
| --- | --- | --- |
| `task-<id>.md` | плагин | текст сообщения; время изменения — «пульс» плагина |
| `claim-<id>` | мост | «задачу взял я»; время изменения — пульс моста |
| `reply-<id>.md` | мост | ответ ChatGPT в markdown |
| `error-<id>.md` | мост | задача не выполнена, внутри причина |
| `../.bridge.lock` | мост | «мост запущен»; второй мост не стартует |

Один ход:

1. Сообщение агенту в Paseo → плагин пишет `task-<id>.md` и раз в 5 секунд
   обновляет его время («жив»).
2. Мост раз в секунду ищет живые задачи без ответа, захватывает задачу
   (`claim-<id>`) и вводит текст в открытый чат ChatGPT — не чаще одного
   сообщения в 20 секунд.
3. Мост сверяет, что в чате появилось именно его сообщение, и ждёт конца
   ответа. «Готово» — это сразу два признака: кнопки «Остановить» нет и под
   ответом появилась панель с «Сгенерировать ответ заново». Плюс текст больше
   не «печатается» и не меняется.
4. Ответ — в `reply-<id>.md`, со списками, ссылками и блоками кода. Плагин
   показывает его в чате Paseo и завершает ход.

Что из этого следует:

- **ID задачи в имени файла.** Ответ на старую задачу не попадёт к новой: плагин
  принимает только файлы с ID текущего хода, остальные удаляет.
- **«Стоп» в Paseo** удаляет файл задачи — мост жмёт «Остановить» в ChatGPT.
- **Пульс.** Задача без пульса — остаток умершего хода, мост её не отправит.
  Но уже отправленную задачу мост не бросает, пока её файл на месте: пульс мог
  пропасть, пока Мак спал. Захват без пульса — от упавшего моста: такую задачу
  мост не отправляет повторно (сообщение могло уже уйти), а пишет ошибку.
- **Ссылки не читаются.** В режиме codexpro ChatGPT сам пишет в рабочую папку и
  мог бы подложить вместо `task-<id>.md` ссылку на `~/.ssh/...`: мост читает и
  пишет файлы, не переходя по ссылкам.
- **Ошибка задачи** уходит в Paseo файлом `error-<id>.md`: ход завершается с
  причиной, а не висит.

## Предохранители

В коде каждый помечен `#внимание-учебно-аналитический-предохранитель`
(`git grep -n "#внимание-учебно"`).

**Объём.**

- Не больше 20 сообщений за запуск; больше — только явным `--limit N`, и не
  больше 500. Лимит проверяет само ядро моста, не только командная строка.
- Не чаще одного сообщения в 20 секунд. Пауза фиксированная, без случайного
  разброса.
- Запускает только человек: автозапуска, демона и расписания у моста нет. Это
  свойство устройства, а не проверка в коде.

**Окружение.**

- Выход в интернет — только `FOREIGN_STRICT` (`AGENTS.md`).
- `codexpro-sandbox` не запущен: из контейнеров OrbStack виден CDP этого Chrome,
  а в нём ChatGPT выполняет команды. Не удалось проверить (нет docker, OrbStack
  не запущен) — мост тоже не запускается.
- Мост подключается к уже открытому Chrome по CDP и сам браузер не запускает.

**Чат.**

- Вкладка chatgpt.com — ровно одна. Мост привязан к существующему чату,
  открытому при запуске; вкладка ушла в другой чат — мост останавливается.
  Новых чатов не открывает.
- ChatGPT занят (идёт ответ или в поле ввода есть текст) — мост
  останавливается: в чужой ход не вмешивается. В чате появилось чужое
  сообщение или ушёл не тот текст — тоже стоп.
- Отправленное второй раз не уходит, в том числе после падения моста.

**Сбои.**

- ChatGPT за 2 минуты не принял сообщение — лимит, капча или слетел вход:
  мост останавливается, ход в Paseo завершается с ошибкой. Обойти не пытается.
- Принял, но за 2 минуты не начал отвечать или отвечает дольше 10 минут —
  «Остановить», ошибка этой задачи, мост работает дальше.
- Ctrl+C, `kill` или закрытое окно терминала — «Остановить» в ChatGPT, ход
  завершается ошибкой «мост остановлен оператором».

Мост — только транспорт: текст из Paseo уходит в ChatGPT, ответ — обратно в
Paseo, команд из переписки мост не выполняет. Считать ли эту переписку каналом
управления для агентов — решение оператора (ai/codexpro#2, нота от
2026-10-09); граница доверия разбирается отдельной задачей.

## Известные ограничения

- «Остановить», нажатую в самом ChatGPT, мост не отличает от обычного конца
  ответа: обрезанный ответ уйдёт в Paseo как полный. Останавливать — «Стоп» в
  Paseo или Ctrl+C моста.
- Интерфейс ChatGPT — на русском: кнопки «Остановить» и «Сгенерировать ответ
  заново» мост ищет по подписи.
- Markdown ответа собирается из разметки страницы: картинки, формулы и блоки
  внутри ячеек таблиц упрощаются.

## Запуск

1. Chrome с ChatGPT — `tools/codexpro-sandbox/README.md`, раздел «Chrome для
   ChatGPT». Открыть чат, который отдаём мосту (лучше отдельный); вкладка
   chatgpt.com должна быть ровно одна.
2. Песочница Paseo с плагином — `tools/paseo-sandbox/README.md`; как открыть
   Paseo и создать агента — `tools/paseo-plugin/README.md`.
3. Мост (перед подключением сам проверит, что выход в интернет — `FOREIGN_STRICT`
   и что `codexpro-sandbox` не запущен):

   ```sh
   cd tools/chatgpt-bridge && npm ci
   node main.ts                 # не больше 20 сообщений
   node main.ts --limit 3       # для пробы
   ```

   Папка задач по умолчанию — `~/work/ai/codexpro/2/sandbox/.ai-bridge/paseo`.

4. В Paseo — сообщение агенту `codexpro/chatgpt`; в чате Paseo появится
   «Задача ушла мосту в ChatGPT». Остановить мост — Ctrl+C (так же —
   `kill` и закрытое окно терминала): текущий ход завершится с ошибкой «мост
   остановлен оператором».

## Живой прогон: чек-лист

Метка `#модельный-учебно-аналитический-контроль`: по этому списку Claude до и
после прогона сверяет, что работа не вышла за учебные рамки, в том числе то,
что человек мог пропустить. Прогон — только по слову оператора.

До прогона:

1. Слово оператора на этот прогон — нотой в Issue, дословно и с датой.
2. `codexpro-sandbox` остановлен; в `paseo-sandbox` нет агентов, которые
   выполняют команды: из контейнеров виден CDP этого Chrome.
3. Chrome запущен по `tools/codexpro-sandbox/README.md`. Вкладка chatgpt.com
   одна — новый отдельный чат; первое сообщение в нём оператор отправил сам
   (до этого у чата нет адреса `/c/…`).
4. В этом чате выключены все коннекторы, прежде всего боевой `CodexPro`
   (ct116). Чат идёт в основном аккаунте, поэтому в ответ может попасть личное
   из памяти ChatGPT: память на прогон выключить или принять это осознанно, в
   сообщениях — ничего чувствительного.
5. Сообщения прогона короткие и заданы заранее; `--limit` — не больше их числа.
6. Запуск с журналом вне песочницы (`-i`: Ctrl+C не обрывает журнал):

   ```sh
   node main.ts --limit 3 2>&1 | tee -i -a ~/work/ai/codexpro/2/bridge-runs.log
   ```

После прогона:

1. Журнал: отправлено не больше лимита («отправлено сообщений за запуск: N из
   L»), паузы соблюдены, причина остановки понятна.
2. Ответы в Paseo совпадают с ответами в чате ChatGPT.
3. Chrome закрыт (Cmd+Q), `curl -s http://127.0.0.1:9222/json/version` не
   отвечает.
4. Итог — нотой в Issue, с SHA моста.

## Если ChatGPT поменял разметку

Селекторы собраны в `SEL` в начале `bridge.ts` (разметка на 2026-10-06).
Поменять там и так же — в имитации `tests/e2e/fake-chatgpt.html`.

## Тесты

Живой ChatGPT тестам не нужен: они работают с имитацией
`tests/e2e/fake-chatgpt.html`, которую Playwright подставляет по адресу
`https://chatgpt.com/c/fake-test`, не выпуская запросы в сеть.

```sh
cd tools/paseo-plugin && npm ci && npm test && npm run typecheck   # протокол и плагин
cd tools/chatgpt-bridge && npm ci && npm run typecheck             # типы моста
cd tests/e2e && npm ci
npx playwright test --project bridge   # мост: ответ, «Стоп», гонки, пульс, ссылки, лимит, пауза, проверки запуска
npx playwright test --project paseo    # цепочка через интерфейс Paseo, нужен paseo-sandbox
```

Тест `paseo` не запустится, пока работает настоящий мост: иначе его сообщения
ушли бы в живой ChatGPT. Прогон на живом ChatGPT — только по слову оператора.
