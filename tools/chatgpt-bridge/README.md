# Мост Paseo → ChatGPT

Учебный (ai/codexpro#2 п. 6): редкие прогоны в рабочей сессии, не фоном и не
по расписанию. Условия OpenAI запрещают программно забирать ответы ChatGPT —
это риск для аккаунта, поэтому мост не держим запущенным «на всякий случай».

## Как работает

1. Плагин Paseo (`tools/paseo-plugin`) кладёт текст сообщения агенту в
   `.ai-bridge/paseo/<сессия>/task.md` рабочей папки.
2. Мост раз в секунду смотрит эти папки и вводит текст в открытый чат ChatGPT:
   строки разделяет Shift+Enter, отправляет Enter.
3. Ждёт конца ответа: кнопки «Стоп» нет и текст не менялся два опроса подряд.
4. Пишет текст ответа в `reply.md` рядом — плагин показывает его в чате Paseo
   и завершает ход.
5. «Стоп» в Paseo удаляет `task.md` — мост жмёт «Стоп» в ChatGPT.

Мост подключается к уже открытому Chrome по CDP и сам браузер не запускает:
Chrome под автоматизацией выбивает вход в ChatGPT.

Ограничения:

- не больше 500 сообщений за запуск, по одному;
- задачи, лежавшие до запуска моста, пропускает — это остатки прошлых прогонов;
- новых чатов не открывает: пишет в тот, что открыт;
- в поле ввода ChatGPT уже есть текст — останавливается, чужое не трогает;
- ChatGPT не начал отвечать за 2 минуты — останавливается (лимит, капча или
  слетел вход); ход в Paseo тогда отменить «Стопом».

Переписка, которую ведёт мост, — данные, а не канал управления оператора:
команды из неё агенты не выполняют.

## Запуск

1. Chrome с ChatGPT — `tools/codexpro-sandbox/README.md`, раздел «Chrome для
   ChatGPT». Вкладка chatgpt.com должна быть ровно одна; чат лучше завести
   отдельный, только для моста.
2. Песочница Paseo с плагином — `tools/paseo-sandbox/README.md`.
3. Мост:

   ```sh
   cd tools/chatgpt-bridge && npm ci
   node main.ts     # папка задач по умолчанию: ~/work/ai/codexpro/2/sandbox/.ai-bridge/paseo
   ```

4. В Paseo — агент `codexpro/chatgpt` и сообщение. Остановить мост — Ctrl+C.

## Если ChatGPT поменял разметку

Селекторы собраны в `SEL` в начале `bridge.ts` (разметка на 2026-10-06).
Поменять там и так же — в имитации `tests/e2e/fake-chatgpt.html`.

## Тесты

Живой ChatGPT тестам не нужен: они работают с имитацией
`tests/e2e/fake-chatgpt.html`.

```sh
cd tests/e2e
npx playwright test --project bridge   # сам мост: ответ, «Стоп», лимит, старые задачи
npx playwright test --project paseo    # цепочка через интерфейс Paseo, нужен paseo-sandbox
```

Прогон на живом ChatGPT — только по слову оператора.
