# Плагин Paseo «ChatGPT (CodexPro)»

Учебный плагин-провайдер для Paseo (ai/codexpro#2). В Paseo он выглядит как
ещё один агент — провайдер `codexpro`, модель `chatgpt`, — но сам не думает:
сообщение агенту кладёт в файл, а ответ берёт из файла. Кто напишет ответ —
мост `tools/chatgpt-bridge`, человек или ChatGPT через CodexPro, — плагину
всё равно.

## Как устроен

- `paseo-plugin.json` — паспорт плагина: имя `codexpro-worker`, нужная версия
  Paseo.
- `index.server.ts` — точка входа: регистрирует провайдера.
- `server/provider.ts` — сам провайдер. Paseo присылает ему запросы
  (`session.open`, `session.prompt`, `session.interrupt`, `session.close`), он
  отвечает событиями: сообщение в чат, ход начат, ход завершён.
- `server/protocol.ts` — правила обмена файлами (протокол v2). Этот же модуль
  импортирует мост, поэтому стороны не могут разойтись в формате.

Обмен идёт через папку `.ai-bridge/paseo/<сессия>/` в рабочей папке агента.
У каждого хода свой ID, он стоит в именах файлов:

| Файл | Кто пишет | Что внутри |
| --- | --- | --- |
| `task-<id>.md` | плагин | ровно текст сообщения агенту |
| `claim-<id>` | мост | «задачу взял я» |
| `reply-<id>.md` | мост, человек или ChatGPT | ответ |
| `error-<id>.md` | мост | почему задача не выполнена |

Один ход:

1. Сообщение агенту → плагин атомарно пишет `task-<id>.md` (читатель никогда не
   увидит его недописанным) и показывает в чате подсказку: если мост запущен —
   «Задача ушла мосту в ChatGPT», иначе — что вставить в ChatGPT и куда писать
   ответ.
2. Пока ход идёт, плагин раз в 5 секунд обновляет время файла задачи — «пульс».
   Задачу без пульса дольше 30 секунд исполнитель считает остатком умершего хода.
3. Раз в секунду плагин проверяет папку:
   - `reply-<id>.md` есть и не менялся между двумя проверками — текст уходит в
     чат как ответ агента, ход завершён;
   - `error-<id>.md` — ход завершается с этой ошибкой;
   - файлы с чужим ID — остатки прошлых ходов, плагин их удаляет.
4. «Стоп» в Paseo → ход отменён, файлы этого ID удалены (мост по этому признаку
   жмёт «Остановить» в ChatGPT).

Файлы плагин читает, не переходя по ссылкам: в режиме codexpro ChatGPT сам пишет
в рабочую папку.

## Учебное и боевое

Чем плагин отличается от боевого провайдера — [`docs/training-vs-production.md`](../../docs/training-vs-production.md),
разделы 07–13: папка вместо очереди, аренда по времени файла, опрос, состояние в памяти,
один ход за раз, общая с ChatGPT рабочая папка. В коде эти места помечены `#учебно-не-боевое-NN`.

Учебное упрощение `#учебно-не-боевое-23`: плагин исполняется как исходники TypeScript, версия
`0.0.0`, Paseo — beta `0.11.0-beta.5`, точные версии зависимостей держит только
`package-lock.json`. В бою — сборка в CI, версионированный подписанный артефакт, стабильные
релизы и автоматические обновления зависимостей.

Ограничения прототипа:

- одна задача за раз в сессии; только текст;
- сообщение во время идущего хода Paseo отклонит: плагин не умеет «подмешивать»
  его в текущий ход (steer). Дождитесь ответа или нажмите «Стоп»;
- после перезапуска демона Paseo ожидающий ход теряется; его файл задачи
  перестаёт «пульсировать», и исполнители его не берут.

## Запуск

Песочница Paseo в Docker и установка туда плагина — `tools/paseo-sandbox/README.md`.

Открыть Paseo и создать агента:

1. Пароль демона — в буфер обмена (на экран не выводится):

   ```sh
   sed -n 's/^PASEO_PASSWORD=//p' ~/work/ai/codexpro/2/sandbox-paseo/paseo.env | tr -d '\n' | pbcopy
   ```

2. В браузере — `http://127.0.0.1:6790`, на стартовом экране «Direct
   connection»: адрес `127.0.0.1`, порт `6790`, пароль — Cmd+V.
3. «New workspace» → папка `workspace` → выбор модели → провайдер
   «ChatGPT (CodexPro)» → модель `chatgpt`.
4. Если отвечать будет мост — сначала запустите его (`tools/chatgpt-bridge/README.md`,
   «Запуск»): при непустой очереди он не стартует.
5. Сообщение в поле «Message the agent» → отправить.

Кто отвечает:

- мост — `tools/chatgpt-bridge/README.md`;
- ChatGPT с CodexPro по подсказке в чате Paseo — только в браузере или профиле
  без CDP, не в Chrome моста (`tools/codexpro-sandbox/README.md`);
- вручную — ID взять из имени файла задачи:

  ```sh
  ls ~/work/ai/codexpro/2/sandbox/.ai-bridge/paseo/*/task-*.md
  echo "Ответ" > ~/work/ai/codexpro/2/sandbox/.ai-bridge/paseo/<сессия>/reply-<id>.md
  ```
