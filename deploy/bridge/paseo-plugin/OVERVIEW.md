ChatGPT в постоянно открытом Chrome, с отдельной постоянной вкладкой для каждого чата Paseo. При следующих сообщениях и восстановлении чата сохраняется привязка к тому же разговору. Закрытая вкладка восстанавливается по сохранённому адресу; если адрес ещё не подтверждён, отправка останавливается для проверки оператором.

Требуются Paseo 0.12.x и Docker-развёртывание Codexpro с браузером и маршрутизатором. Вход в ChatGPT и проверки выполняются вручную через экран браузера. Остановка маршрутизатора оставляет Chrome открытым.

Провайдер принимает текстовые сообщения и поддерживает отмену. Сообщения, ответы и привязки хранятся в отдельном локальном каталоге состояния, доступном провайдеру и маршрутизатору. Каталог задаётся CODEXPRO_STATE_DIR; по умолчанию это .paseo/codexpro в домашнем каталоге демона. Переписка отправляется в ChatGPT через текущую сессию браузера. Для ручного управления сначала останавливают маршрутизатор, затем явно запускают его снова. Изображения, steer и инструменты Paseo этим провайдером не передаются.
